# Archived: v1.x custom-engine tools

These scripts belonged to my first approach (v1.1–v1.3), which replaced parts of the AWS decision engine with
custom rules, a command guard and a coordinate adapter. That approach performed worse than the stock agents and was
abandoned; its code is not part of this repository, so these scripts will not run as-is.

They are kept because they produced the measurements that changed the approach: the real pitch scale, the ball's
axes, the 120-second match length, and the replay regression test design (real match ticks through all handlers,
mutation-checked).
